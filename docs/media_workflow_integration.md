# Media Workflow Integration

The website is one stage in a broader recurring media workflow.

```text
Service recording
      ↓
Media preparation and file naming
      ↓
Upload-ready video and thumbnail
      ↓
Publishing platform
      ↓
Website sermon or media archive
```

## Integration Principles

- File names and dates should remain consistent across processing and publishing.
- The website should link to final public media, not working files.
- Archive structure should support browsing by date and topic without duplicate uploads.
- Live-translation access should remain distinct from recorded-media archives.
- Credentials and upload steps remain outside the public repository.

This reduces repeated manual interpretation between recording, processing, publishing, and maintenance.
