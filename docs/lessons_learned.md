# Lessons Learned

## Maintainability Is a Product Requirement

A visually complete site can still fail operationally when routine updates require fragile workarounds. Navigation, plugin choices, page structure, and media organization should be judged by ongoing maintenance effort.

## Information Architecture Comes Before Styling

Rebuilding an inherited site is easier when content is first grouped by visitor purpose. Styling a confusing structure only makes the confusion more polished.

## Related Workflows Need Clear Boundaries

Sermon processing, public video hosting, event updates, and live translation are separate systems. The website should connect them through stable public links rather than absorb every operational detail.

## Sanitization Requires Deliberate Separation

A portfolio case study can demonstrate decisions, tradeoffs, and workflow design without publishing credentials, private content, hosting details, or production exports.

## Small Regression Checks Prevent Rework

After changes, the highest-value checks are often simple: mobile navigation, event cards, archive links, media pages, and translation access.
