# Event Calendar Refinement

The event calendar is treated as an operational information surface rather than decorative content.

## Design Priorities

- Month navigation must be obvious.
- Cards should remain readable on phones.
- Date, time, location, and event title should be distinguishable at a glance.
- Recurring events should not overwhelm one-time announcements.
- Expired events should leave the primary view automatically or through a simple maintenance step.

## Review Questions

- Can a first-time visitor find the next service or event?
- Can a mobile user move between months?
- Can an authorized editor update an event without changing page layout?
- Does the calendar remain readable when titles vary in length?

The public repository documents design questions without publishing production plugin settings.
