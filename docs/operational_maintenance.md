# Operational Maintenance Model

A website rebuild is not complete when pages first go live. The recurring operating model determines whether the site remains useful.

## Recurring Tasks

- Update public events and service information.
- Publish new sermon or media links.
- Review mobile layout after plugin or theme changes.
- Check navigation, archive links, and translation access points.
- Remove outdated announcements.
- Confirm recurring content can be updated without changing unrelated pages.

## Change Control

1. Record current behavior.
2. Identify affected pages and workflows.
3. Make the smallest practical change.
4. Check desktop and mobile views.
5. Verify event, gallery, media, and translation links.
6. Keep a rollback path.

## Handoff Goal

Routine updates should be understandable to another authorized operator without requiring hosting internals or custom-code knowledge.
