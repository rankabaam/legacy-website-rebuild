# Responsive Community Language Program — Portfolio Addendum

A public-facing community education landing page was developed after the initial site-rebuild portfolio documentation. The independent sample at [community_hangul_program.html](../samples/community_hangul_program.html) demonstrates the **general UX approach**, rather than copying a production WordPress page.

## Demonstrated layout

- Self-contained hero, introduction, curriculum cards, session information, image-free gallery placeholders, and inquiry / registration explanation.
- Accessible section navigation with anchor links.
- Mobile-responsive stacking and touch-friendly calls to action.
- No real organization branding, photography, enrollment information, contact details, forms, plugins, or production CSS.

## Current status clarification

The sample is a standalone HTML mockup and not a WordPress export, Gutenberg block export, or deployment to the live organization website. The production page's actual application and inquiry links are deliberately omitted.

To review: download `samples/community_hangul_program.html` and open locally in any modern browser.
