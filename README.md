# Legacy Website Rebuild

A sanitized WordPress rebuild case study focused on maintainability, information architecture, media workflows, and public-facing reliability.

## Overview

This project documents the replacement of an aging legacy CMS with a more maintainable WordPress-based structure. The work included reorganizing navigation, rebuilding public content, improving media access, and connecting the site to recurring operational workflows such as sermon publishing and live translation access.

## What the Project Demonstrates

- Assessing an inherited legacy website and identifying maintainability risks
- Rebuilding information architecture around real user needs
- Migrating public-facing content into a modern CMS
- Organizing sermon, gallery, and media archives
- Supporting repeatable content-maintenance workflows
- Integrating access points for related media and translation systems
- Separating public portfolio documentation from production infrastructure

## Generalized Project Flow
